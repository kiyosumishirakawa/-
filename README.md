## 8. グループレビュー記録

### 8-1. 指摘一覧

| No | 指摘内容 | 指摘者 | 対応 |
|:---|:---|:---|:---|
| 1 | ブザーを鳴らす間隔を明確にした方がよい | 細山さん | 修正する。Caution時とDanger時でブザーの間隔を分ける |
| 2 | Safe / Caution / Danger の距離基準をどう決めたのか説明した方がよい | 細山さん | 修正する。机上デモで分かりやすい距離として、50cmと20cmを基準にする |
| 3 | センサーが壊れていた場合や測定できない場合の判断方法が必要 | 細山さん | 修正する。測定値が0cm以下、または400cmを超える場合は異常値として扱う |

### 8-2. レビューを受けて変更した点

- ブザーの鳴り方を明確にし、Caution時はゆっくり、Danger時は短い間隔で鳴らす方針にした。
- 距離の判定基準として、50cm以上をSafe、20cm以上50cm未満をCaution、20cm未満をDangerとした。
- センサー異常時の対応として、測定値が0cm以下または400cmを超える場合は異常値と判断し、LCDにエラー表示を出してブザーを鳴らさない方針にした。
