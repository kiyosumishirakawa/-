5/15〜5/20　AI駆動開発
■意識・工夫したこと
AIが出した内容をそのまま使うのではなく、要件定義・基本設計・詳細設計のどの部分に対応しているかを確認しながら進めた。チーム内では役割分担を行い、自分は進捗リーダーとして作業状況を確認しながら、担当した金額表示処理の実装・修正を行った。

■直面した課題と解決策
【課題】AIが生成したコードや設計内容を理解するのに時間がかかり、意図した結果にならない場合もあった。また、結合時に同じ意味の変数に対してメンバーごとに異なる変数名を使用していたため、修正に時間がかかった。
【解決策】AIの出力内容をチームで確認し、必要な部分を取捨選択して修正した。変数名については、結合テスト時に共通で使用する名前へ統一し、担当部分が他の処理と正しく連携できるようにした。
5/21〜5/28　組み込み開発実習
■意識・工夫したこと
実装前に要件定義・基本設計・詳細設計を行い、入力・処理・出力の流れを整理してから作業を進めた。LCD、超音波センサー、ブザーを一度に組み合わせるのではなく、部品ごとに単体確認を行ってから段階的に結合した。また、利用者に分かりやすいように、距離だけでなくSafe、Caution、Dangerなどの状態もLCDに表示するよう工夫した。

■直面した課題と解決策
【課題】配線やピン設定が多く、LCDが正常に表示されない場面があった。また、超音波センサーの値が-1になる場合や、100cm以上の距離表示など、最初の設計だけでは十分に整理できていない部分があった。
【解決策】配線とコード上のピン設定を一つずつ確認し、LCD表示の問題を修正した。センサー値が-1の場合は近すぎる危険状態として扱い、Too Close / Dangerと表示してブザーを連続音にするよう仕様を見直した。さらに、millis()を使用して距離測定、LCD表示、ブザー制御を止めずに動かせるようにした。
