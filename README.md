■直面した課題と解決策
【課題】LCD、超音波センサー、ブザーなど複数の部品を使用したため、配線やピン設定が多く、正しく接続できているかを確認するのに時間がかかった。また、各部品を一度に組み合わせると、問題が起きた時に原因を特定しにくいと感じた。
【解決策】最初から全てを結合するのではなく、LCD、超音波センサー、ブザーをそれぞれ単体で動作確認した。その後、配線とコード上のピン設定を一つずつ確認しながら段階的に結合し、問題の原因を切り分けながら修正した。
