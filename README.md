### TC-01: ボタン連打

* **操作**: スタートボタンを1秒間に10回以上連打する
* **期待**: チャタリングせず、状態が不自然に連続遷移しない
* **結果**: 連打しても異常な動作は発生せず、タイマーの状態遷移は想定通りだった
* **壊れた？**: No
* **原因（仮説）**: チャタリング対策により、短時間の入力変化が安定して処理されたため
* **修正した？**: 修正不要

### TC-02: カウントダウン中のスタート再押下

* **操作**: カウントダウン中にスタートボタンを押す
* **期待**: カウントダウン中にボタンを押すと一時停止し、再度押すと再開する
* **結果**: カウントダウン中にボタンを押すと一時停止し、再度押すと正常に再開した
* **壊れた？**: No
* **原因（仮説）**: RUNNING、PAUSED の状態遷移が想定通りに動作したため
* **修正した？**: 修正不要

### TC-03: 0秒到達後の放置

* **操作**: カウントダウンが0になった後、何もせず30秒待つ
* **期待**: 表示は00.00で止まり、終了メロディが鳴る
* **結果**: 00.00表示のままFINISHED状態になり、終了メロディが正常に鳴った
* **壊れた？**: No
* **原因（仮説）**: remainingSeconds が0以下になった時点でFINISHED状態へ遷移し、メロディ再生処理が実行されたため
* **修正した？**: 修正不要

### TC-04: リセットの連続

* **操作**: スタート→すぐリセット→スタート→すぐリセットを5回繰り返す
* **期待**: 毎回正しく初期値に戻る
* **結果**: 5回繰り返しても毎回正常に初期状態へ戻り、表示とブザーも異常なかった
* **壊れた？**: No
* **原因（仮説）**: resetTimer() により状態、残り時間、ブザー処理が正しく初期化されたため
* **修正した？**: 修正不要

### TC-05: 電源再投入

* **操作**: カウントダウン中にUSBケーブルを抜いて、3秒後に挿し直す
* **期待**: 初期状態から再スタートする
* **結果**: 再接続後、setup() から再起動し、初期状態としてポテンショメータで設定した時間が表示された
* **壊れた？**: No
* **原因（仮説）**: 電源再投入によりArduinoが再起動し、初期化処理が正常に実行されたため
* **修正した？**: 修正不要
