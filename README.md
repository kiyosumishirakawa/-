## Problem

テストケースを確認する際に、最初は各項目が何を目的としているのかをすぐに理解できませんでした。
特に、基本テスト・ハードウェアテスト・ソフトウェアテストの違いや、期待結果と実際の結果をどのように記録すればよいかを整理するのに時間がかかりました。
また、測定値や動作結果が期待と異なる場合に、それをすぐに不具合と判断するのではなく、測定方法やプログラムの仕様と結びつけて考える必要があると感じました。

## Try

次回は、テストを実施する前に「何を確認するテストなのか」「期待結果は何か」「異常が出た場合にどこを疑うべきか」を先に整理してから作業したいです。
また、結果だけでなく、確認した手順や判断理由も記録し、後から見ても原因や修正内容が分かるようにしたいです。
ソフトウェアテストでは、Serial Monitorのログや状態遷移を活用し、ハードウェア由来かソフトウェア由来かを切り分けながら確認していきたいです。
