### 3-1. 部品一覧とピン接続

| 部品名 | 型番・種類 | Arduinoピン | 入力 / 出力 | 備考 |
|:--|:--|:--|:--|:--|
| LCD1602 RS | 16x2 LCD Module | D7 | 出力 | LCDの制御用ピン |
| LCD1602 E | 16x2 LCD Module | D8 | 出力 | LCDの制御用ピン |
| LCD1602 D4 | 16x2 LCD Module | D9 | 出力 | 4ビットモードのデータ線 |
| LCD1602 D5 | 16x2 LCD Module | D10 | 出力 | 4ビットモードのデータ線 |
| LCD1602 D6 | 16x2 LCD Module | D11 | 出力 | 4ビットモードのデータ線 |
| LCD1602 D7 | 16x2 LCD Module | D12 | 出力 | 4ビットモードのデータ線 |
| 超音波センサー Trig | Ultrasonic Sensor | D5 | 出力 | 距離測定用のトリガー信号を出す |
| 超音波センサー Echo | Ultrasonic Sensor | D6 | 入力 | 反射して戻ってきた信号を受け取る |
| パッシブブザー | Passive Buzzer | D3 | 出力 | 距離が近い場合に警告音を鳴らす |
| ポテンショメータ | 10K Potentiometer | なし | 出力補助 | LCDのコントラスト調整に使用 |
| Arduino UNO R3 | マイコンボード | なし | 処理 | センサー値の取得、距離判定、LCD・ブザー制御を行う |
| Breadboard | ブレッドボード | なし | 配線用 | 回路を仮組みするために使用 |
| Jumper Wire | ジャンパーワイヤ | なし | 配線用 | 各部品を接続するために使用 |
| USB Cable | USBケーブル | なし | 給電・書込 | Arduinoへの給電とプログラム書き込みに使用 |

**ピン競合チェック結果：** 競合なし

D0/D1はSerial通信専用のため使用しない。  
LCD1602はD7〜D12、超音波センサーはD5・D6、パッシブブザーはD3を使用するため、同じArduinoピンを複数の部品で使用していない。

### 3-2. 電気的考慮事項

| 用途 | 判断・計算メモ |
|:--|:--|
| LCDコントラスト | 10KポテンショメータでVOピンを調整する |
| LCDバックライト | Aを5V、KをGNDに接続する |
| パッシブブザー | D3からtone()で信号を出力する |
| センサーの動作電圧 | 超音波センサーは5Vで動作させる |
| ピン競合 | D0/D1は使用せず、各部品で使用するピンが重ならないようにする |
