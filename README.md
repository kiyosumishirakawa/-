## 4. 異常系・エラー処理の方針

| 異常ケース | 発生条件 | 検知方法 | 対応方針 |
|:--|:--|:--|:--|
| 距離を測定できない | Echo信号が返ってこない | pulseIn() の結果が0になる | LCDに「Out of range」と表示し、ブザーは鳴らさない |
| センサー異常値 | 距離が0cm以下、または400cmを超える | distanceCm の値を確認する | 測定範囲外として扱い、警告音を出さない |
| LCD表示の残り文字 | 表示更新時に前回の文字が残る | LCDの表示を確認する | 表示更新時に画面をクリアする |
| ブザーの誤作動 | 異常値でブザーが鳴る | 距離判定前に異常値を確認する | 異常値の場合はnoTone()でブザーを止める |
