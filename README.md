4-1. 苦労したこと

最初は、LCDに Safe、Caution、Danger などの状態だけを表示する予定でした。
しかし、グループレビューで「状態だけでなく、障害物までの距離も表示した方が分かりやすい」という意見をもらいました。

状態だけの表示では、利用者がどのくらい障害物に近づいているのか分かりにくく、警告の具体性が不足していると感じました。

4-2. 対処したこと

レビュー内容をもとに、LCDには状態だけでなく、距離も cm 単位で表示するように仕様を変更しました。
通常時は測定した距離と Safe、Caution、Danger の状態を表示するようにしました。

また、100cm以上の場合は細かい距離を表示せず、Over 100cm / State:Safe と表示することで、安全な状態であることが分かりやすいようにしました。
近すぎる場合は Too Close / State:Danger と表示し、危険な状態であることを明確にしました。

4-3. 学んだこと

今回の経験から、機能が正しく動くだけでなく、利用者にとって分かりやすい表示にすることも重要だと学びました。
また、レビューで指摘をもらうことで、自分だけでは気づけなかった改善点を見つけることができました。

今後は、実装する機能だけでなく、使う人が見たときに分かりやすいかどうかも意識して設計したいです。
