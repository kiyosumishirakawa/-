## 6. 結合テスト計画（V字モデル：基本設計 ↔ 結合テスト）

| No | テスト対象（requirements.md の必須機能から転記） | テスト手順（操作方法） | 期待する結果 | 実際の結果 | 合否 |
|:---|:---|:---|:---|:---|:---|
| 1 | 超音波センサーで障害物までの距離を測定できる | センサーの正面に物体を置き、距離を変化させる | 距離の変化に合わせて測定値が変わる | ← 実装後に記入 | [ ] |
| 2 | 測定した距離をcm単位でLCD1602に表示できる | 物体をセンサーの前に置き、LCD表示を確認する | LCDに「Dist: 〇〇cm」のように距離が表示される |  | [ ] |
| 3 | 距離に応じて「安全」「注意」「危険」の状態を判定できる | 物体を50cm以上、20〜50cm、20cm未満の位置に置く | 距離に応じてSafe、Caution、Dangerが切り替わる |  | [ ] |
| 4 | 障害物が一定距離以下になった場合、ブザーで警告できる | 物体を50cm未満、20cm未満に近づける | Cautionではゆっくり鳴り、Dangerでは短い間隔で鳴る |  | [ ] |
| 5 | 距離が近い場合、LCDに警告メッセージを表示できる | 物体を20cm未満に近づける | LCDにDangerなどの警告メッセージが表示される |  | [ ] |
| 6 | 異常系：距離を測定できない | センサーの前に物体を置かない、または測定範囲外に向ける | LCDに「Out of range」などを表示し、ブザーは鳴らない |  | [ ] |
